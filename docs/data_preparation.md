# Data Preparation

## Objetivo

Preparar os dados para a construção da ABT e da modelagem.

## Pontos identificados no Data Understanding

### Valores ausentes

- Variáveis imobiliárias com mais de 60% de nulos.

### Variáveis com comportamento anômalo

- DAYS_EMPLOYED.

### Variáveis categóricas

- 16 atributos categóricos exigirão encoding.

### Identificadores

- SK_ID_CURR será mantido apenas para rastreabilidade.

### Scores externos

- EXT_SOURCE_1
- EXT_SOURCE_2
- EXT_SOURCE_3

Precisam ser analisados durante a preparação.
